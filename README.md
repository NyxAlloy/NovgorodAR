# Новгородские Вести — WebAR

**[Открыть WebAR на телефоне](https://raw.githack.com/NyxAlloy/NovgorodAR/main/ar.html)** · [Обложка для второго экрана или печати](assets/cover.jpg)

Откройте демо в Safari на iPhone или Chrome на Android. Если raw.githack покажет кнопку **Open the page**, нажмите её. На экране «Газета оживает» нажмите **Включить камеру и звук**, разрешите доступ при первом запросе и наведите телефон на обложку. При сохранённом разрешении видео включается сразу. Компьютер с локальным сервером для этого не нужен.

Наведите камеру на портрет Деда Мороза в выпуске от 27 декабря 2026 года. Прямо на портрете Дед Мороз помашет рукой. Шестисекундный ролик повторяется, пока газета в кадре. Для распознавания используется квадратная иллюстрация. QR под иллюстрацией открывает онлайн-демо. После запуска камеры наведите её на портрет Деда Мороза.

## Запуск на компьютере

В папке, где лежит `index.html`, откройте PowerShell и запустите сервер.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Откройте [локальный прототип](http://localhost:8000/) и нажмите «Включить камеру и звук». Для проверки держите перед камерой распечатку или откройте `assets/cover.jpg` на втором экране. Кнопка «Закрыть» работает и во время запуска. Сервер останавливается сочетанием Ctrl+C.

Для запуска по сети откройте сайт по HTTPS. MindAR 1.2.5 загружается после включения камеры, поэтому для теста нужен интернет.

## Проверка на Android по USB до публикации

1. Запустите сервер на компьютере командой выше. Подключите Android кабелем, включите отладку по USB и подтвердите подключение к этому компьютеру на телефоне.
2. В Chrome на компьютере откройте `chrome://inspect/#devices`. Включите **Discover USB devices** и дождитесь появления телефона.
3. Нажмите **Port forwarding**, включите **Enable port forwarding**, укажите слева `8000`, справа `127.0.0.1:8000` и нажмите **Done**.
4. В Chrome на телефоне откройте `http://localhost:8000/`. На экране компьютера откройте `assets/cover.jpg` или используйте распечатку. На телефоне нажмите «Включить камеру и звук» и наведите её на обложку.

[Инструкция Chrome по пробросу порта через USB](https://developer.chrome.com/docs/devtools/remote-debugging/local-server)

## Публикация на GitHub Pages после подтверждения

1. Распакуйте `NovgorodAR.zip`. Поместите файлы проекта в корень ветки `main`. В корне должны оказаться `index.html`, `ar.html`, `app.js`, `styles.css`, `targets.mind` и папка `assets`.
2. В репозитории откройте **Settings → Pages → Build and deployment**. Выберите **Deploy from a branch → main → /(root) → Save**.
3. Дождитесь успешного развёртывания и откройте адрес из раздела Pages в Safari на iPhone или Chrome на Android. Все пути к файлам проекта относительные и подходят для адреса вида `https://username.github.io/repository/`.

[Настройка источника публикации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Проверка на телефоне

| Действие | Что должно произойти |
| --- | --- |
| Открыть страницу и нажать «Включить камеру и звук» | Браузер запрашивает разрешение при первом запуске. После инициализации видно изображение камеры и статус «Ищем обложку…». |
| Навести камеру на весь лист | Дед Мороз начинает махать рукой. Появляется статус «Обложка обнаружена ✓». |
| Медленно сдвинуть и наклонить лист | Четыре угла видео следуют за соответствующими углами квадратного портрета. |
| Полностью убрать лист и вернуть его | Видео исчезает и звук останавливается. При повторном распознавании ролик начинается сначала. |
| Нажать «Закрыть» и снова включить | Камера освобождается, стартовый экран возвращается. При новом запуске лист распознаётся снова. |

Если камера работает, но обложка долго не находится, расправьте лист, уберите блики и начните с вида прямо сверху. Для проверки отказа в доступе запретите камеру при первом запросе. На экране камеры появятся причина отказа и кнопка повторной попытки.

## Иллюстрация, QR и звук

- `assets/winter-illustration.jpg` — оригинальная квадратная иллюстрация 1536 × 1536. `targets.mind` и его опубликованная копия `assets/winter-portrait.mind` получены из неё с помощью MindAR 1.2.5.
- `assets/cover.jpg` и `assets/winter-newspaper.jpg` — газетная полоса для печати. QR расположен под иллюстрацией. `assets/winter-qr.png` содержит тот же код для сайта.
- `assets/ded-moroz-b0b59858.mp4` — сжатый ролик с собственной звуковой дорожкой. Кнопка звука управляет и роликом, и колокольчиками.
- `assets/chime.wav` — колокольчики из ветки `Development`. Стартовая кнопка включает камеру и подготавливает звук. Звон звучит один раз при обнаружении портрета и останавливается при потере цели или закрытии камеры. Микрофон не запрашивается.
- `ar.html` подключает версии `app.js` и `styles.css` с хешем содержимого в имени. При изменении этих файлов обновите копии в `assets` и ссылки в `ar.html`.
