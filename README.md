# Новгородские Вести — WebAR

**[Открыть WebAR на телефоне](https://raw.githack.com/NyxAlloy/NovgorodAR/main/camera.html)** · [Обложка для второго экрана или печати](assets/cover.jpg)

Откройте демо в Safari на iPhone или Chrome на Android. Если raw.githack покажет кнопку **Open the page**, нажмите её. На экране «Газета оживает» нажмите **Включить камеру**, разрешите доступ при первом запросе и наведите телефон на обложку. При сохранённом разрешении видео включается сразу. Компьютер с локальным сервером для этого не нужен.

Наведите камеру на обложку выпуска от 27 декабря 2026 года. На иллюстрации появятся снег и мерцающие огни. Для распознавания используется вся обложка. QR-код в плашке «Оживи обложку!» открывает онлайн-демо. После запуска камеры наведите её на всю обложку.

## Запуск на компьютере

В папке, где лежит `index.html`, откройте PowerShell и запустите сервер.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Откройте [локальный прототип](http://localhost:8000/) и нажмите «Включить камеру». Для проверки держите перед камерой распечатку или откройте `assets/cover.jpg` на втором экране. Кнопка «Закрыть» работает и во время запуска. Сервер останавливается сочетанием Ctrl+C.

Для запуска по сети откройте сайт по HTTPS. MindAR 1.2.5 загружается после включения камеры, поэтому для теста нужен интернет.

## Проверка на Android по USB до публикации

1. Запустите сервер на компьютере командой выше. Подключите Android кабелем, включите отладку по USB и подтвердите подключение к этому компьютеру на телефоне.
2. В Chrome на компьютере откройте `chrome://inspect/#devices`. Включите **Discover USB devices** и дождитесь появления телефона.
3. Нажмите **Port forwarding**, включите **Enable port forwarding**, укажите слева `8000`, справа `127.0.0.1:8000` и нажмите **Done**.
4. В Chrome на телефоне откройте `http://localhost:8000/`. На экране компьютера откройте `assets/cover.jpg` или используйте распечатку. На телефоне нажмите «Включить камеру» и наведите её на обложку.

[Инструкция Chrome по пробросу порта через USB](https://developer.chrome.com/docs/devtools/remote-debugging/local-server)

## Публикация на GitHub Pages после подтверждения

1. Распакуйте `NovgorodAR.zip`. Поместите файлы проекта в корень ветки `main`. В корне должны оказаться `index.html`, `camera.html`, `app.js`, `effects.js`, `styles.css`, `targets.mind` и папка `assets`.
2. В репозитории откройте **Settings → Pages → Build and deployment**. Выберите **Deploy from a branch → main → /(root) → Save**.
3. Дождитесь успешного развёртывания и откройте адрес из раздела Pages в Safari на iPhone или Chrome на Android. Все пути к файлам проекта относительные и подходят для адреса вида `https://username.github.io/repository/`.

[Настройка источника публикации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Проверка на телефоне

| Действие | Что должно произойти |
| --- | --- |
| Открыть страницу и нажать «Включить камеру» | Браузер запрашивает разрешение при первом запуске. После инициализации видно изображение камеры и статус «Ищем обложку…». |
| Навести камеру на весь лист | Появляются снег, огни и статус «Обложка обнаружена ✓». |
| Медленно сдвинуть и наклонить лист | Снег движется внутри иллюстрации, огни остаются на тех же участках рисунка. |
| Полностью убрать лист и вернуть его | При потере цели эффекты исчезают. После повторного распознавания они возвращаются. |
| Нажать «Закрыть» и снова включить | Камера освобождается, стартовый экран возвращается. При новом запуске лист распознаётся снова. |

Если камера работает, но обложка долго не находится, расправьте лист, уберите блики и начните с вида прямо сверху. Для проверки отказа в доступе запретите камеру при первом запросе. На экране камеры появятся причина отказа и кнопка повторной попытки.

## Обложка и анимация

- `assets/cover.jpg` — эталон размером 1055 × 1491 пиксель. `targets.mind` уже скомпилирован из этого файла и содержит одну цель с индексом 0.
- `camera.html` показывает видеопоток и прозрачный холст эффектов. `app.js` проецирует холст на обложку по матрице MindAR.
- `app.js` управляет камерой, запуском, закрытием и событиями трекинга. `effects.js` рисует снег и огоньки после обнаружения цели. Видеослой с мимикой в этот прототип не входит.
- При замене макета или QR-кода заново скомпилируйте итоговую обложку и замените `targets.mind`. Если пропорции изменились, обновите пропорции холста в `camera.html`. [Компилятор MindAR](https://hiukim.github.io/mind-ar-js-doc/tools/compile/)

## Что проверено

QR на готовой обложке проверен в исходном размере, после уменьшения до ширины 790 пикселей и при повороте на 5°. Во всех трёх случаях считывается адрес `camera.html`. MindAR 1.2.5 собрал из этого JPEG одну цель размером 1055 × 1491.
